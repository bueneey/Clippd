# clippd

Open marketplace for memecoin clipping. Creators fund a campaign in SOL. Anyone clips. Views get verified. Clippers get paid from the vault.

Live: [https://getclippd.fun](https://getclippd.fun/)

X: [@clippdpump](https://x.com/clippdpump)

## Run locally

```bash
cd onchainclipping.com/onchainclipping.com
cp .env.example .env
python3 server.py
```

Open [http://127.0.0.1:5173](http://127.0.0.1:5173). Production is always [https://getclippd.fun](https://getclippd.fun/).
